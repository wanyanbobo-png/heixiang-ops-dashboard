# 黑箱健身 · 线上运营数据看板 V1.0

这是给厦门五缘湾「黑箱私教健身馆」制作的轻量级运营数据看板。**不需要服务器、不需要安装程序，也不需要把 Excel 提交到 GitHub。**

## 功能

- **经营总览**：已登记累计发布、点赞、评论、收藏、点评好评，周度趋势和平台占比。
- **作品分析**：尝试从抖音、小红书的作品导出表识别标题、日期、播放/阅读量、点赞、评论和收藏，查看播放与互动率排名。
- **周报记录**：导入 Excel 汇总表、直接新增一周记录、导出周报 CSV。
- **转化追踪**：记录咨询、预约、体验、成交订单和金额；没有数字就显示“—”，不会把点评好评算作成交。
- **数据管理**：支持 .xlsx / .xls / .csv / .json，生成导入模板与 JSON 备份。

## 第一步：在电脑打开本地网页

把项目中的 `index.html`、`styles.css` 和 `app.js` 放在同一个文件夹，双击 `index.html` 打开。默认显示的是**演示数据**，不是实际经营记录。

读取 Excel 依赖一个公开的 XLSX JavaScript 组件，因此首次直接导入 Excel 时请保持网络连接。如果加载失败，可在 Excel/WPS 中把需要的工作表另存为 CSV，再导入。

## 第二步：导入你自己的数据

1. 点击左侧「数据管理」→「选择文件」。
2. 优先选择《黑箱线上运营数据总览版.xlsx》。识别到「周度区间」和「已登记累计」后，自动展示周度趋势和累计值，**不会把月汇总与周报再相加**。
3. 再导入抖音/小红书作品明细 Excel。如果导出表头无法识别，下载「作品明细模板.csv」，将数据整理到对应列再导入。
4. 若要计算真实转化，请下载「转化记录模板.csv」，填写后台或实际跟进数据再上传。

### 数据口径

- 抖音、小红书发布合计才是「内容发布」；美团/点评好评单独展示。
- 月度已登记累计和周度趋势为**两个独立视图**。如果已登记累计包括周报数据，绝不再合并。
- 「单条作品总播放量」是作品导出文件的统计量，未必与周报统计期一致，不与周度数据强行合并。
- 作品互动率 = （点赞 + 评论 + 收藏） / 播放或阅读量。只在播放量有效时计算。
- 到店体验、成交订单必须来自明确的转化记录；不能从评价或备注的自然语言猜测。
- 有些 10 月的日期可能没有登记，不能将「没有记录」理解成「没有发布/没有订单」。

## 第三步：把代码上传到 GitHub

1. 登录 [GitHub](https://github.com/)，进入 https://github.com/new 。
2. 仓库名填写：`heixiang-ops-dashboard` 。选择 **Public**（用于 GitHub Pages 免费展示），不勾选 Add a README file；点击 Create repository。
3. 打开仓库页面 → **Add file → Upload files**。
4. 上传 `index.html`、`styles.css`、`app.js` 和 `README.md`（可选择同时上传两份示例模板）。**不要上传实际业务 Excel、会员姓名、电话、微信、订单信息。**
5. 点击 **Commit changes**，这就保存了第一个版本。
6. 进入 **Settings → Pages**，在 **Build and deployment** 下选择 **Deploy from a branch**，分支选 `main`、文件夹选 `/(root)`，点击 **Save**。
7. Pages 生效后，在 **Settings → Pages** 点击 **Visit site**。一般网址格式：`https://你的GitHub用户名.github.io/heixiang-ops-dashboard/`。

> 小提示：如果你已经创建了公开仓库，也可以把仓库链接发到当前聊天，我可以通过已连接的 GitHub 帮你创建和修改仓库代码文件。

## 日常怎么用

- 每周从平台后台导出 Excel/CSV，打开网站，点「导入数据」。
- 对于无法导出的咨询/预约成交数据，用标准 CSV 模板维护。
- 数据存当前浏览器，不是跨设备同步。**每次更新完请下载 JSON 备份**；在另一台设备用「数据管理」导入这个备份。
- 浏览器隐私模式、删除站点数据、换手机会导致本地数据丢失。请保留你的原始 Excel。

## 数据隐私与局限性

- 纯静态前端，**没有开发任何把选中 Excel 上传至服务器的请求**。仅使用公共 CDN 加载 Excel 解析库；严肃处理敏感信息前，应自行审查依赖和托管环境。
- GitHub Pages 网站可能对所有人可访问，因此不能把真实运营数据硬编码进网页或上传仓库。
- localStorage 的数据仅存储在具体浏览器对应站点。不同网页地址的本地存储互不相通。
- 平台导出格式可能更改。本版是**对常见列名的自动识别**，并非保证兼容所有历史表头。遇到识别失败，请转为模板 CSV。
- 若第一次运行就导入真实数据，看板自动替换演示数据，不会把演示记录混入真实总量。
