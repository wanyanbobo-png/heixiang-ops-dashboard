# 自动采集与公开发布

## 当前交付边界

取消 Supabase；删除浏览器云登录、数据库适配器和 SQL。旧浏览器 localStorage、导入历史、Excel/CSV/JSON 导入、备份和时间筛选不迁移、不上传。自动指标单独展示，避免与历史报表重复累计。生产文件 `data/platforms.json` 没有模拟指标，首次打开会显示待授权。自动作品日期按北京时间，数值为最近采集时的累计值，不是当日增量；点赞/评论不代表成交或周报汇总。

此版本实现抖音官方 API 适配器和 Actions 流程，但**尚未验证真实接口权限或采集成功**。2026-11-11 本环境访问官方文档被出站代理 403 拒绝，以下是需要应用管理员在官方控制台复核的接入条件，不代表已获平台批准。

## 抖音接入

官方入口：https://developer.open-douyin.com/ （文档与应用管理）。在开放平台创建适用的应用，完成主体资质、应用审核、绑定重定向地址，并申请自己的账号视频列表权限（`video.list`，以控制台实际批准的 scope 和当前接口文档为准）。账号所有者通过官方 OAuth 页面同意授权；没有授权不得抓取或用 Cookie 替代。

适配器固定调用 `https://open.douyin.com/oauth/refresh_token/` 获取短期 access token，再分页调用 `/api/douyin/v1/video/video_list/`。若当前应用类别或审核提供的接口、字段、scope 不同，应在上线前按官方文档修订适配器并复测，不能将本地 mock 测试视为真实接通。

初次授权由管理员在可信本机/官方工具完成：授权请求使用随机 `state` 并在回调校验，redirect URI 必须与控制台一致；使用短期授权 code、client key、client secret 在官方 `/oauth/access_token/` 交换令牌。不要把回调 code、client secret、access/refresh token 放到 Pages、工单或仓库，不要在浏览器端实现令牌交换。此静态网站不承担 OAuth 回调后端；没有授权服务时由管理员安全完成首次接入。

在仓库 Settings → Secrets and variables → Actions 添加以下 **Secrets**（不是提交文件）：

- `DOUYIN_CLIENT_KEY`：应用标识。
- `DOUYIN_OPEN_ID`：本次授权账号标识。
- `DOUYIN_REFRESH_TOKEN`：授权后的刷新令牌；有效期、续期和撤销按官方规则处理。
- `DOUYIN_PUBLIC_ITEM_IDS`：管理员逐一确认仍公开且有再发布权限的作品 item_id JSON 数组，例如 `["<官方接口返回的作品ID>"]`。不要使用此示例值直接运行。

应用审批和账号 OAuth **不自动授予将分析数据公开发布的权利**。管理员核实平台条款、授权范围及各作品公开状态后，设置 Actions Variable `DOUYIN_PUBLICATION_APPROVED=true`。没有该确认或任一必要 Secret 时不调用接口，且清空旧的公开指标。切勿提交账号私密分析、播放量、观看时长、粉丝画像、经营订单、用户数据、评论正文、原始接口响应或完整 OAuth 响应。

只投影作品 ID 的 SHA-256、发布日期、点赞数、评论数。哈希只用于稳定去重，不宣称能匿名化原标识。接口返回的私密标记为 true 或未审核的作品被排除；其他作品必须先在 Secret 白名单逐项批准。不发布标题、URL、账号 ID 或任何接口额外字段。作品转私密/删除或撤销公开许可时，立即更新许可列表并手动运行任务；若需紧急删除历史公开数据，管理员也应清理 Git 历史和 Pages 缓存。失败时页面明确显示旧快照时间，不假装实时成功。

令牌刷新后检查账号匹配；刷新令牌轮换时安全失败，不把新令牌写入 Git/日志。管理员在可信工具重新授权/续期并更新 Secret 后重跑。无自动修改 Secrets 权限，不承诺授权永久有效。

## Actions 和 Pages

合并后，在 Settings → Pages 将 Source 设置为 **GitHub Actions**。工作流仅在 `main` 运行真实采集，支持手动触发和每天北京时间 08:15、16:15、次日 00:15 的计划执行；GitHub 的定时任务可能延迟，闲置仓库也可能停用计划。无需每天下载 Excel。合并/审核由用户处理，本任务不合并 main。

Actions 需要 contents:write 提交唯一的公开 JSON；分支保护可能阻止机器人推送，届时需要仓库管理员配置允许此工作流的更新策略（不要绕过保护）。同一工作流使用 pages:write、id-token:write，通过官方 Pages artifact 部署公开站点；这是因为 GITHUB_TOKEN 提交不会触发传统分支式 Pages 构建。只打包网页、脚本、CSV 模板和公开 JSON，不打包测试、OAuth 工具或私密文件。采集失败仍提交安全失败状态，保留上次完整成功数据并部署状态，同时将采集 job 标记失败。并发被串行化；推送冲突显式失败，不强推。

首次配置后手动运行 `Collect approved public metrics`，核实工作流成功、JSON 只含许可字段、Pages 部署完成、页面最后成功时间变化及作品数量正确，再依赖定时执行。无需安装 Python 第三方包。运行器只需访问 GitHub Actions 基础设施、`open.douyin.com`；开发环境如需查阅文档，还需放行官方文档域名。仓库设置的 Secrets 与云开发环境配置互不替代。
